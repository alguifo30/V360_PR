# Vision 360 · Plan Fórmula 1N

Presentación en HTML: portada con agenda, apertura animada, video del equipo, comercial, tres iniciativas (Alertas de fraude, Carterizados y Multisesión), tiempo de entrega y cierre.

## Cómo abrirla

1. Descarga o clona el repositorio.
2. Abre `index.html` en Chrome o Edge. No necesita internet ni servidor.
3. Cuando el botón diga «Iniciar en pantalla completa», púlsalo o usa → / Espacio en el presentador.

Los controles, la contingencia y cómo editar están en `Manual_de_operacion.md`.

## Estructura

| Ruta | Contenido |
|---|---|
| `index.html` | Escenas y textos |
| `styles.css` | Diseño y animaciones |
| `motion.js` | Apertura animada |
| `presentation.js` | Portada, transiciones, métricas y controles |
| `assets/` | Videos, logos, fondo institucional y tipografías |
| `capturas/` | Cada lámina como imagen de respaldo |
